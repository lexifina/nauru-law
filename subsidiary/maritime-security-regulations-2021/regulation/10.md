# 10 Non-compliance
(1) A ship that is unable to comply with the Act or these Regulations or to meet the requirements set for its security level shall notify the port security officer of a Nauru port before:
(a) conducting any ship-port interface at a Nauru port; or
(b) entering a Nauru port, whichever occurs first.
(2) Where a ship has any difficulty implementing the security measures required by Regulation 9(9), the ship security officer shall, as soon as practicable, inform the port security officer of those difficulties, in which event the ship security officer and port security officer shall liaise about, and co-ordinate an appropriate response to, those difficulties.
