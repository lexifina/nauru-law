# 39 Project Implementation
(1) The Managing Committee shall enter into project implementation agreements with successful grant applicants under this Part on behalf of the Fund.
(2) A project implementation agreement under subregulation (1) shall include:
(a) names of the parties;
(b) description of the project;
(c) date of commencement of implementation;
(d) project work schedule and deliverables;
(e) monitoring, evaluation and verification measures;
(f) reporting requirements; and
(g) a grievance redress mechanism.
(3) A successful grant applicant under this Part shall provide the following project implementation reports:
(a) quarterly financial and implementation reports; and
(b) a project completion report with consolidated financial statements.
(4) Project implementation reports under subregulation (3) shall include monitoring, evaluation, and reporting mechanisms as set out in the Guidelines.
(5) The Guidelines shall set out prescribed forms for project reporting.
