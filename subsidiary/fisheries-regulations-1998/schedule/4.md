# SCHEDULE 4
[Regulation 27]
REPORT FORMS
[Sch 4 am GN No 719/2010 reg 3 and Sch clauses 2.1–2.2, opn 1 Jan 2011]
(1) Weekly Reports
(a) report type (WEEK);
(b) trip begin date;
(c) date and time (GMT);
(d) international call sign;
(e) licence number;
(f) vessel name;
(g) Regional Register number;
(ga) observer name and country;
(h) position (to one minute of arc);
(i) catch on board by weight by type;
(j) intended action, as: WEEK / TBD / ddmmyy / TIME / CALL SIGN / LICNO / VESSEL NAME / R.REGNO / OBSNAME / OBCOUNTRY / LA 1111 / LO 11111 / SJ www YF xxx BE yyy OTH zzz / INTENDED ACTION
