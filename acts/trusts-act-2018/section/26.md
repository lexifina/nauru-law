# 26 Offence of failure to register trust or file annual returns
(1) If a trust is not registered in accordance with Sections 12 and 13, each trustee commits an offence and upon conviction is liable to:
(a) a penalty not exceeding $5,000; and
(b) a penalty not exceeding $50 for each day that the failure continues.
(2) If an annual return is not filed for a registered trust in accordance with Section 15, each trustee commits an offence and upon conviction is liable to:
(a) a penalty not exceeding $5,000; and
(b) a penalty not exceeding $50 for each day that the failure continues.
