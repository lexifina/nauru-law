# 12 Penalty for applying false trade description to exports
No person shall:
(a) knowingly apply any false trade description to any goods intended or entered for export or put on any ship or boat for export, or brought to any port or place for the purpose of export; or
(b) knowingly export or enter for export or put on any ship or boat for export any goods to which a false trade description is applied. Penalty: $200.
