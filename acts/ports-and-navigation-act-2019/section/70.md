# 70 General requirement of compliance with IMO Codes
A person shall not perform a dangerous goods cargo function or handle dangerous goods except in accordance, as applicable, with:
(a) the IMDG Code
(b) the IMSBC Code;
(c) the IBC Code or the BCH Code;
(d) the IGC Code or the GC Code or the EGC Code; and
(e) the INF Code.
